# Native official Vision runtime kernel

`NativeOfficialVision` adds a separate one-use journal for the protected structured Vision adapter. It reuses the existing Native source/CPU frame evidence, shared Vision models/normalization, immutable key factory, human identity records, scoped rights exceptions and cost ledger. Existing fixture intent/getter/session contracts remain unchanged. The kernel is implemented and mock/local-real tested. Signed HTTP, protected configuration and recovery-only server wiring are now documented in [NATIVE_OFFICIAL_VISION_HTTP.md](NATIVE_OFFICIAL_VISION_HTTP.md); Studio review and planner/QC use remain separate work.

The operator gate defaults off. Consent explicitly binds the current authenticated Owner record/revision/expiry, workspace, project revision/document, one source observation, asset and sampled frames, transcript/scene versions, current rights evidence, frozen provider configuration, explicit mock acknowledgement and finite 60–900 second window. Raw booleans, request identifiers and explicit finite VND decimals are validated again at the service boundary. Changed, revoked or expired identities cannot inherit old approval. Registered rights or a current scoped Owner exception are required for real dispatch; unknown/restricted rights and fixture media cannot enter real analysis. Protocol mocks use a separate unverified-rights marker and grant no publishing/license authority.

The approved per-operation ceiling must cover the configured estimate and maximum input/output token envelope, including the larger input/cached-input rate. The project budget checks existing paid reservations, unknown exposure and the new ceiling before private resolution. A unique cost intent conservatively reserves the approved ceiling before dispatch; budget failure requires approval. Actual billed cost stays null without independent billing evidence. Calculated usage is persisted separately. Mock operations retain false paid/external flags and do not masquerade as spend.

Claims are atomic and one-use. Exact request replay returns historical evidence without another call; changed content under the same key conflicts. Admission rechecks current Owner, finite window, configuration, project/source/rights/actual frame binding before the key, after the key and immediately before HTTP send. Dispatch uses the existing fixed bounded/private adapter and a 120-second hard bound. Cancellation is local and does not claim remote rollback. Timeouts, rate-limit responses, interrupted claims and uncertain outcomes have no automatic retry or consent renewal.

Complete bounded response observations are recorded before semantic parsing or late Owner/configuration/source fences. Known hashes/usage survive late revocation, edits, expiry, invalid semantics, missing usage and cancellation. If recovery already settled an immutable unknown cost receipt, a later complete observation is preserved alongside it rather than rewriting the old receipt or declaring success. Partial responses remain unknown. Successful results bind the response, cost operation, actual Native frame references and adapter provenance; original paid/external capability declarations remain distinct from actual mock calls and unknown invoices.

Results persist structured frames, scenes, provider/model provenance, OCR/object/subject/quality fields, sampled best/thumbnail candidates and four center-crop plans requiring attention. Continuous subject tracking, decoded presentation timestamps and calibrated confidence remain false. Mock semantics stay mock. Results grant no automatic planning, timeline mutation, publishing or Owner UAT approval. Historical reads require neither current credentials nor a current provider configuration; scope, source, response, cost, usage, mock identity, rights and crop evidence are validated against their original records. Rehashed mock/paid/invoice/crop/cost claims are rejected.

Three additive journals persist intents, complete observations and events. Claimed work blocks backup.
