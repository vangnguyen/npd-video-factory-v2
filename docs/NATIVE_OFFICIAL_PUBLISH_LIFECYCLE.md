Original Wave 9 and Master Spec sections 45–47, 52 and 55/56 remain open. This increment extends the existing [bounded worker](NATIVE_OFFICIAL_RESUMABLE_WORKER.md) with explicit consent renewal, pre-dispatch backoff and owned restart-cost recovery. Renewal is a separate typed Owner action with snapshot hash, current dispatch version, strict acknowledgement, bounded TTL and idempotency key. It verifies current human identity, unchanged source/review/account/configuration and the existing session binding. The prior grant is revoked atomically, the new grant records its ancestry, and the dispatch retains phase, private reference and acknowledged bytes. Repeated and concurrent exact requests issue one grant. Changed key payloads, stale versions/sources, active requests, uncertain initialization and expired upload sessions reject. A still-unsent prepared review retains only its first initialization; no renewal permits a second initialization. An already uploaded video can receive fresh consent for processing reads without needing a still-live upload URI. This requires explicit current Owner authentication and refreshed credentials where expired, not automatic authority extension.

Read rate limits append scoped response-hash/delay observations. Chunk Retry-After and read backoff are checked before credential resolution, account reads, costs or upload dispatch. Expiry/time/scope evidence is validated, and renewal cannot erase the provider delay. Restart and independent worker instances retain the same timer. Processing observations and previous responses remain append-only.

Upload cost operations use their durable intent ID; the cost ledger refuses a second dispatch for the same ticket. Startup recovery finalizes only unfinished, non-paid, owned official-worker operation namespaces as outcome unknown. It sends no requests, decrypts no private files and never modifies finished receipts or unrelated operations. Dispatch recovery still requires same-session reconciliation before more bytes. This is conservative evidence after interruption; it does not invent an acknowledgement or billed amount.
