# Immutable Windows Google OAuth custody

Native now has an explicit private vault for dedicated Google client configuration, finite pending PKCE authorization state and access/refresh grant generations. Constructor and state discovery do not decrypt or create files. The directory must be absolute, unlinked and outside Source and Native state. Windows DPAPI uses a separate domain for each kind, purpose and workspace. Files have protected DACLs for only the current user and LocalSystem, are flushed before atomic rename, and never replace an existing destination.

Public receipts contain opaque references, public target/client fingerprints, purpose/alias, ciphertext hash/size and raw disabled markers. Reads check those bindings, bounded bytes, private envelope/schema, original client receipt, current protected paths and ciphertext again after decryption. Client configuration, pending state and grants reject scope/purpose/target/alias drift, tampered or hardlinked files, naive times and numeric mock markers. Malformed private models do not emit serializer warnings containing secret values. Token/code/PKCE values are excluded from public receipts and representations.

Explicit refresh custody creates a new generation and retains the old bytes/reference. Prior purpose/configuration/target/mock transport and any known refresh expiry cannot expand. Unknown refresh expiry stays null. No active pointer changes automatically. Historical expiry and pending state remain readable; the shared protocol refuses using expired authorization or access. Missing private client custody prevents dependent grant resolution. These operations neither confirm an account nor renew Owner/background-read/publication consent.

The retained rehearsal uses eight synthetic encrypted files, four mocked token exchanges and four grant proofs. Actual ACL inspection verifies every private file. A Native backup carries only public references and an unapproved fixture project; it excludes private files, tokens, code and PKCE values. A fresh restore and separate process resolve the original references only through the separately mounted original private vault. An unmounted private vault cannot resolve the restored metadata. Original grant bytes and earlier finite analytics history remain exact.

The first rehearsal stopped because the ACL helper inherited PowerShell 7 module paths while invoking Windows PowerShell. No acceptance was recorded for that run. The helper now removes the inherited module-path variable and runs hidden; a new state/private/output/restore root passed. Prior fixture roots remain separate.

This is custody architecture only. Current human admission, durable one-use callback/operation claims, cost audit/account verification, signed routes/Studio/credential resolver integration and genuine OAuth/provider/browser/Owner/deployment acceptance remain pending. Default Native/API provider, scheduler and publishing settings stay unchanged. A production secret-service implementation remains separate from Native Windows DPAPI. All original North Star requirements continue.
