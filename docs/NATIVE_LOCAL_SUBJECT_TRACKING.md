# Local subject-region tracking and canonical crop paths

This Wave 3F/4 component adds actual local temporal image matching to the Native source-footage workflow. It does not certify semantic face/person/object detection, every-frame tracking, calibrated confidence, real ASR, Owner/browser acceptance or full Mode B.

An editor selects a textured region in the first source frame. A queued `source_tracking` job decodes bounded grayscale PNG samples with FFmpeg `showinfo` source PTS after container-start normalization. NumPy performs normalized cross-correlation using FFT products and independently verified window sums. A separable binomial filter handles subpixel resize phase; the immutable original template and safety thresholds remain fixed. Loss, textureless input and competing similar regions stop tracking without automatic identity switching. Long sources adapt sampling to a maximum of 600 frames; motion between samples is unmeasured.

The measured coordinates, source/analysis/request fingerprints, timestamp evidence, PNG references/hashes, provider/model, nullable confidence, match coefficient and ambiguity margin are saved in immutable job results and versioned project history. Confidence stays null; the measured similarity is not a probability or semantic prediction. Source bytes, audio, transcript, subtitles and timeline remain unchanged until the editor explicitly applies a result.

Apply uses the existing source-reframe engine and exact timeline version/hash. Four target ratios produce smoothed source-seconds keyframes in the same canonical timeline used by shot and advanced views. Loss/ambiguity or a subject box that cannot fit the smoothed crop keeps `center_crop` with `needs_attention=true`. All paths require preview and fresh human approval. Rehashed project evidence cannot impersonate the original successful job; changed frames, stale results and altered sources reject. Copies retain geometry and inherited evidence without transferring measurement or review authority.

The Vietnamese Studio panel shows the source video, region percentages, queued status, saved results and an explicit crop acknowledgement. Runtime capability gating, editor permission, CSRF/origin checks, draft protection, workspace/context fences and no replay after an uncertain queue response remain separate from rendering approval. Native bridge delivery can emit the existing content-free `video.analysis.completed` event; no Agent Hub call or shared database is required.

The local acceptance index is [local-subject-tracking-evidence.json](north-star/local-subject-tracking-evidence.json). A fresh signed HTTP rehearsal exercises the shipped controller with a fixture DOM and two generated, known-motion source videos. The positive case tracks decoded coordinates against independent source ground truth, creates an audible preview and renders a passing 1080×1920 final. Three independently decoded rendered frames verify the green subject's expected position from known motion and canonical crop, with maximum horizontal error below one output pixel. The negative case loses the subject, uses center fallback and produces `failed_qc` because freeze exceeds the existing threshold; final approval and publishing stay blocked. Its failed candidate is retained as negative evidence, never a passing final.

Trusted backup/fresh restoration and a separate process verify both projects, original job-bound tracking results and all sampled frame hashes without new jobs/provider calls. Owned temporary roots are cleaned after export. Failed trials are retained: initial integration/import/fixture issues, subpixel sensitivity before preprocessing, a brittle existing source-wiring assertion and the genuine negative QC rejection. The latter is preserved rather than weakening QC.

The prior Windows runtime concern receives a separate control: all 51 intelligence cases pass under the unchanged default Windows event-loop policy without a faulthandler timer. The historical diagnostic access violation is not reproduced by this control; its cause and production soak remain unproven. A test-only Selector result alone had not certified default runtime.

Real face/person/object detectors and tracking validation on genuine uploaded footage, all-frame/occlusion/scale/rotation tracking, automatic semantic seeds, remaining profile/media/provider/platform gaps, actual browser/non-developer/Owner, original A/B/C and isolated production acceptance remain required. Source preservation, Phase 10 technical readiness and Owner-UAT-required stay separate; full program flags remain NO. No paid/provider/TTS operation, real publishing, main merge, production installation or deployment occurred.
