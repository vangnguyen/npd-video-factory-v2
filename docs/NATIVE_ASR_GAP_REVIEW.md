# Native ASR word review at source audio gaps

This Wave 3B/3D/3I/8/15 component implements an operator path for `ASR_WORD_OVER_SOURCE_AUDIO_GAP_REVIEW_REQUIRED`, against Master Spec sections 22 and 24. It preserves provider evidence, records human word corrections and resumes the existing job. Original full Mode A/B, genuine speech/provider, Owner UAT, original A/B/C and production remain unaccepted.

After a completed provider result is normalized and validated, a gapped source checkpoints an immutable candidate with its original PCM transcript, source/snapshot identity, media/audio hashes and original upload/create/completion receipts. The failed job can then be reviewed locally. Candidate/audio/source corruption blocks reads, saves and resume. A cached completed candidate can be processed without loading provider status, credentials or a new transport. Historical jobs lacking this checkpoint retain their existing behavior; they are not silently re-certified.

`/api/projects/{project_id}/asr-gap-reviews` reads source words, missing intervals and review history. The item route saves explicit word text/source start/end/removal decisions with exact project revision, candidate hash, expected version, idempotency key and actor identity. Saving creates an append-only SQLite review version and event; it does not queue work, edit source/canonical media or grant video approval. The existing explicit job-resume route queues that same acknowledged job. Source playback is scoped to the job/project/asset and verifies original bytes; signed Range reads are supported. Auth, edit permission, CSRF and origin checks precede mutation bodies.

Remaining words must be finite, ordered, positive, inside source/provider-input bounds and outside observed missing intervals. Removing all words is refused. No interpolated or fabricated word timing/confidence is introduced. Current human corrections carry null confidence and explicit human timing provenance; original raw provider PCM/text/words remain separate. Validation reconstructs the corrected transcript and its source mapping from the stored candidate and immutable review receipt. Normalized human-derived transcripts are labelled `is_original_evidence=false`, including their initial normalized version; audio and Source editors preserve that distinction.

The Assets panel has a first-class **Từ nhận diện cần kiểm tra** card. Initialization is inert. Explicit read shows source playback, original words and gaps. Word controls permit text/start/end/removal, with 25 words per page and 2,000-word/50-version bounds. Acknowledged save and known-job resume are separate actions. Unsaved edits are guarded; retries reuse the same idempotency key. Viewer/active/archived/unrelated-dirty/stale/foreign contexts cannot install or submit edits. The word fields use a scoped responsive grid; readonly history states are explained explicitly. The failure action directs users to this card.
