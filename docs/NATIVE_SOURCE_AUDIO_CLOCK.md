# Native decoded audio and ASR source clocks

This Wave 3B/3D/3I/6D/8/15 component binds newly measured waveform and transcript times to observed source-audio PTS. It does not certify genuine speech recognition, provider accuracy, full Mode A/B, original A/B/C, Owner UAT or production.

New waveform v2 concurrently drains mono float PCM and bounded sanitized `ashowinfo` rows. `copyts/start_at_zero` preserves normalized container timing, and explicit `asettb=1/sample_rate` fixes clock units. Sample counts, rate/channels, printed/rational clocks and continuity are validated. Bins retain the observed source origin; no leading silence is fabricated. Noncontiguous/overlapping clocks require review instead of implicit filling/removal. [FFmpeg timestamp options](https://ffmpeg.org/ffmpeg.html#Advanced-options) and [ashowinfo](https://ffmpeg.org/ffmpeg-filters.html#ashowinfo) describe the underlying metadata.

New Native ASR WAV extraction checkpoint includes its observed 16 kHz clock and hashed sanitized log. A continuous clock permits the affine map `source_seconds = provider_pcm_seconds + observed_source_start_seconds`. Original provider PCM transcript evidence stays in a separate immutable record with its hash and original response reference; mapped transcript preserves confidences/text while shifting segment/word bounds. Mapping reconstruction participates in saved-source validation. Unknown historical clocks retain their existing semantics and are not re-certified. Known-job resume reuses original extraction/upload/create receipts; a bad clock stops before provider upload.

The source signal recipe advances to v5. Native v3/v4 fingerprints and stored timelines remain readable; new results expose the new recipe. Silence detection uses normalized source timestamps, and waveform UI accepts both v1 and v2 with source-relative trim/split/move coordinates. Original raw speech evidence and transcript editing stay versioned. Publishing/default human gates are unchanged.

Evidence is indexed in [source-audio-clock-evidence.json](north-star/source-audio-clock-evidence.json). A generated-tone video with delayed audio yields an observed first PCM time of 0.47675 seconds, not a guessed 0.5-second label. Waveform begins at that observed time. Explicit mock ASR starts at PCM zero and maps to 0.47675 source seconds; source bytes/timeline/approval are unchanged. The retained bundle contains source video, extracted WAV/log/clock, original/mapped transcripts, analysis and project state. Mock known-job resume records one upload and one creation only. Backup/new-process restoration preserves original and mapped evidence without jobs/provider calls. Rehearsal roots are cleaned after export.

Native real-media and protocol tests cover delayed clocks, mapper integrity, noncontiguous pre-dispatch rejection, v3/v4 preservation, waveform/transcript consumers and related source paths. Studio tests cover both waveform versions. Consumer tests were updated for the new version name without weakening amplitude/provenance checks.

Genuine VI/EN/automatic speech/provider acceptance, discontinuous-audio segment mapping, complete browser/non-developer/Owner flows, full audio/render/QC/AV-sync acceptance across real media, original A/B/C and production remain open. No paid/provider request, TTS inference, real publishing, main merge or deployment occurs.
