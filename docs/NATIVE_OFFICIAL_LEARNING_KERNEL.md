# Native qualified descriptive learning kernel

Wave 12 adds immutable Native channel-learning snapshots over the qualified winner journal. It reuses the existing pure `LearningPolicy`, `LearningObservation` and descriptive aggregation in `app.learning_models` without ORM, a provider SDK or changes to the API rule bodies. This increment is the kernel; signed controls and Trend/Idea/Media/Template feedback integration remain separate work.

Strict versioned requests bind an existing qualified winner assessment and exact snapshot SHA256, a bounded learning policy, explicit recommendation-only acknowledgement and an exact Boolean protocol-mock acknowledgement when needed. Current human Owner authority is checked before idempotent replay and again after selection before insertion. One SQLite transaction validates the anchor and all selected original winner assessments, their frozen selected peers, qualified analytics/response-cost/receipt/source/render feature lineage and consistent score evidence. There is no provider request, credential resolution, recurring grant, media mutation, publishing action or budget change.

Learning scope preserves exact workspace/account target digest/platform/provider/transport/report query/render format/niche/frozen channel identity. Duration buckets may differ: each selected relative winner score was independently qualified against its own matching-duration winner cohort. A shared winner policy digest, algorithm and available-factor/weight basis are required. These descriptive relative scores do not assert equal publication age, exhaustive channel coverage, causal impact or direct absolute performance across different duration baselines.

Selection scans at most five hundred saved assessment rows and chooses at most one hundred distinct remote posts. Only original observations at or before the anchor collection time are eligible. Within matching scope/policy, the latest saved assessment for a remote post is considered first. A newer insufficient or changed-factor-basis assessment cannot revive an older sufficient score. Duplicate assessments do not inflate sample/control counts; incompatible scope/policy/factor basis, sparse sources and post limits retain exclusion/truncation evidence.

Each observation retains source/result/assessment/render/timeline/feature hashes, qualified relative score and the original recorded features. Missing trend/hook/visual/subtitle/voice labels remain null; unsupported long labels are excluded rather than truncated. Duration uses the existing bucket function. Publishing windows remain null without response-bound posted-time evidence. Other frozen production features, including idea, scene count, music, topic and CTA, remain in the referenced immutable source metadata. Semantic labels are annotations or edit facts and are not independently certified Vision classifications.

The preserved shared rule requires at least three group posts and three distinct posts with a different known feature for controls. Unknown feature values cannot become controls. A configured positive median-score difference produces a `recommendation_candidate`; weak differences produce `no_positive_association`; inadequate samples stay `insufficient_data`. All seven recommendation dimensions retain group/control snapshot references, sample counts, missing-feature counts and median differences. The output recommends a reviewed experiment, without autonomous action or performance guarantees. Protocol-mock observations remain synthetic, never mix with real transport, and cannot become real audience feedback.

Two additive Native journals retain frozen learning snapshots and events; backup includes both counts. Saved snapshots freeze the anchor/source references, selected assessment references, observations, policy, scope, original authority, exclusions/truncation and recommendations. Historical reads revalidate those same original sources and recompute observations and aggregation without rescanning later history. New data, current project edits/archive, expired current authority or removed factories cannot rewrite a saved snapshot. Rehashed reference, score, source, scope, dimension or qualification mutations fail closed. New creation still requires current Owner authority. Bounded publication-filtered history and cursors remain workspace/project scoped.
