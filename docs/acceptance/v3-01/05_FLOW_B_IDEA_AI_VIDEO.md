## Acceptance contract

One owner-approved business brief must produce a traceable chain:

`brief -> sources -> claim map -> script version -> shot/asset plan -> licensed/generated assets ->`
`timeline -> preview -> approval -> final render -> QC package`.

Every factual claim must identify its source and retrieval time. Every final asset must have a
RightsRecord, model/provider/workflow identifier, request/response hash where allowed, transformation
lineage and retention policy. Provider metadata is evidence; a credential or successful HTTP code
alone is not acceptance.
