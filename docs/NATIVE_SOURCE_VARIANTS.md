# Native source master and platform variants

Native Studio Video review now offers explicit profile selection, draft creation and paginated family history. The versioned configuration catalog defines YouTube 16:9, Shorts/TikTok/Reels 9:16, social 1:1 and feed 4:5 with exact output geometry. These are format profiles, not authorized channel accounts or publishing grants. Source master projects can create up to six independent linked drafts from one frozen canonical revision. Narrated Native Mode A master variants remain a separate gap.

The existing identity-rebinding engine preserves source assets, original bytes, edited transcript/word decisions, scene analysis, supporting-media plans, audio decisions and measured CPU frame evidence. New project/analysis/transcript/scene/plan identities retain explicit parent-record hashes and derived-evidence provenance. No source file is copied during variant creation, no model or provider is called, and reused evidence is never represented as a fresh measurement. The master document, timeline, approval and version history stay unchanged; a content-free master event records the family creation.

One additive SQLite table persists immutable workspace/master/request/catalog/child-history bindings and digests. Strict revisions and timeline version, active source checksums, magic bytes, measured geometry, profile uniqueness/geometry, bounded history, same-origin/auth/CSRF and editor permission guards run before mutation. Request replay returns the same family even after later master edits; a changed body with the same key conflicts. All child documents/versions/events and the final family record share one transaction. A simulated final-event failure rolls back every child. Read validation checks the frozen master version and every child's original version rather than substituting current editable content; altered/rehashed profile or child membership fails closed.

Each enabled visual source uses a measured-geometry center-crop plan for the requested ratio, with confidence zero and `needs_attention=true`. Visual track locks are respected; derivation never silently unlocks them. The UI explains this crop policy before creation. Source/manual crops are reviewable on each independent canonical timeline through the existing shot and advanced editors. Audio and subtitles stay bound to saved edit decisions. Supporting images receive their own geometry-aware plans. Generic project copies drop variant membership metadata so they do not impersonate registered family members.

New drafts inherit no approval, jobs, previews, final reviews or publishing consent. Each requires a fresh preview, explicit human approval, final rendering, QC and final watch/listen review through the existing workflow. History labels describe the state at creation; they do not claim that a later edited/rendered variant remains unapproved. Scoped no-store HTTP routes expose the catalog and workspace/master-bound keyset history. Studio loads neither catalog nor history automatically, renders uploaded names as literal text, rejects stale/wrong-scope responses and uses stable keys for retrying the same intent.

The final `native-variants-contract-n2` rehearsal generated fresh three-second synthetic footage/tone, retained an explicit saved ASR fixture and ran real local scene/audio/eight-frame analysis. A technology niche from `examples/technology-explainer.request.json` entered fixture configuration; no core niche logic changed. Six source variants independently produced actual effects previews, final MP4s and passing FullQC at their configured dimensions. Native render manifests bind each exact canonical timeline. All six mixes have identical PCM hashes. Saved assets/transcripts/scene/frame evidence was reused; the mix and render steps still ran independently and their intermediates were **not** cached. The technology configuration was seeded in the owned fixture, not selected through a Native ChannelProfile UI.

The rehearsal made sixteen authenticated requests, preserved master/document/source hashes, retained immutable family history and recovered exact master/children/jobs/history in a new process. An independently checksum-anchored offline package restored the six final files, project versions, events and configuration to a fresh owned root. Existing absolute render-result paths were not rewritten; new rendering after restore remains untested. Six previews/finals and their timeline/subtitle/audio/manifest/QC/cost/probe/checkpoint evidence are retained separately. Earlier n1 outputs remain unchanged; final n2 adds an explicit comparison with the actual Native render manifest rather than an absent optional field.

Unit/HTTP/DOM tests cover all formats, reuse, independent review boundaries, concurrent replay, later master edits, atomic rollback, real file corruption, locked tracks, B-roll geometry, generic-copy separation, version/scope/cursor/catalog/child-history integrity, authorization-before-body, literal text and stale responses. Exact source/log/media hashes and counts are in `docs/north-star/native-variants-evidence.json`.
