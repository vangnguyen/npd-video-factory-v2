Its constructor requires the strict target-bound journal, encrypted vault, actual artifact guard, operation meter and official client. Each write requires fresh Owner configuration gates, scoped current consent/identity/rights/production bindings, exact credential/account/scopes/expiry, real source byte/range checks and committed dispatch intent. Missing key/optional crypto refuses before even account lookup. A refreshed token after QC receives another exact account check. A request has a sixty-second overall timeout; changed execution/cost policy refuses admission. A mock transport marks the parent and costs as mock and cannot silently become a live transport. A mock parent cannot become live.

This worker reports `uploaded` separately from unverified processing/publishing and does not finalize a publication receipt.
