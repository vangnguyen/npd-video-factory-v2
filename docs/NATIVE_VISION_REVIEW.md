# Native structured Vision review

Native Studio Assets now offers a capability-gated review panel for saved structured Vision intents and results. It reads measured source-frame observations and displays actual PNGs beside explicitly labelled fixture captions, scene descriptions, objects/person/face boxes, Vietnamese OCR, environment/action, composition, quality and confidence. History and source reads do not dispatch a provider. Owner management permission, session authentication, same-origin and CSRF checks run before consuming mutation bodies. Viewer and editor accounts cannot create or process fixture predictions.

Two additive SQLite tables preserve scoped intents, frozen revision/document/source/observation/transcript/scene evidence, result digests and bounded content-free audit events. Requests select one to sixteen checksum-bound frame observations. The default official mode persists `NOT_CONFIGURED` with no result or mock fallback. Fixture mode requires strict explicit acknowledgment; it uses a generic provider contract without property-specific semantic assumptions. Source magic bytes, original-file hashes and measured PNG references are checked before fixture dispatch. Queue replay, concurrency and restart preserve one result. Cancellation is terminal; a completion-event failure rolls back the entire result before recording failure.

The provider implements the shared provider-neutral `VisionProvider` shape and returns typed shared frame/scene/composition/quality contracts. Its prediction text and boxes are fixed contract fixtures. It does **not** perform semantic inference on pixels. Provider/model, confidence, requested sample timestamp, actual frame reference and source provenance persist separately from the existing measured CPU facts. Decoded source PTS remains unavailable. History validation refuses altered digests, rehashed frame/provenance/provider substitutions and inconsistent crop plans. Source/frame endpoints retain their existing independent integrity checks.

Fixture predictions cannot automatically select media, B-roll, crop or QC decisions. Subject tracking is unavailable, subject tracks remain empty and B-roll relevance remains null. All four ratio plans retain exact deterministic `center_crop`, confidence zero and `needs_attention=true`; no crop is applied to the canonical timeline. Fixture best-frame/thumbnail rankings are labelled as fixture quality only. Source footage, CPU observations, transcript versions, timeline and human approvals are not mutated by the Vision service. Unknown actual external/local compute costs remain null; no paid or external operation occurs.

The isolated `native-vision-contract-n3` rehearsal generated a fresh six-second synthetic testsrc/tone video, ingested its real bytes, retained a saved ASR fixture, ran actual local scene/audio and eight-frame CPU measurement, then made nine authenticated Native HTTP requests. It saved structured fixture semantics bound to the normalized transcript and measured scene; verified replay, cancellation, official unavailability and two history pages; and compared unchanged source/project/CPU evidence. Fresh-process read and checksum-anchored backup to a fresh root restored exact histories and PNG hashes. This is real local media IO and explicit mock semantic output, not genuine speech recognition, semantic inference, automatic tracking or Owner acceptance. Failed import and test-configuration attempts remain retained.

Native backup counts both new tables and rejects pending Vision work before creating an offline snapshot. Tests cover cancellation/restoration, actual frame corruption before dispatch, revision drift, provider frame mismatch, rehashed result tampering, scope/cursors, strict admission, concurrency, event rollback, framework/GPU-free imports and authenticated HTTP authorization-before-body. DOM tests cover literal text rendering, actual image URLs, acknowledgment, replay, source selection, stale responses and contradictory result rejection. They do not certify browser usability at 1366/1920/2560 or non-developer Owner UAT.

Configured official semantic dispatch, independent credentials/cost/budget handling, real model/frame acceptance, subject tracking, calibrated confidence, semantic asset/scene/B-roll/thumbnail/QC consumers and complete Native/browser/Owner flow remain. The existing API real adapter remains preserved. `MEDIA_INTELLIGENCE_READY`, `AUTO_EDIT_MODE_READY`, `IMPLEMENTATION_COMPLETE`, `REAL_PROVIDER_ACCEPTANCE_COMPLETE` and `VIDEO_FACTORY_NORTH_STAR_READY` remain `NO`; production is undeployed. Exact tests, source/log/evidence hashes and failed attempts are indexed in `docs/north-star/native-vision-evidence.json`.
