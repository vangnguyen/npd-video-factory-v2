# Canonical narrated music loops

Master Spec section 38 and Waves 6C/6D/6E remain authoritative. This increment adds opt-in measured music overlaps to the accepted Native narrated workflow. Speech, perceptual balance, legal, provider, browser, non-developer and Owner acceptance remain separate.

Studio exposes the existing music-loop control for a saved narrated shot timeline only when the server advertises `native_narrated_music_loop`. Intake accepts `X-VF-Music-Loop-Crossfade`, zero by default, with finite values from zero to one second and at most three decimals. A positive interval cannot exceed half the decoded music duration. Authentication, editor permission, CSRF, revision, size, MIME, decoding and upload-attestation gates precede registration. Failed or stale intake removes only its newly created artifacts. Upload attestation keeps effective rights unknown.

Positive overlap stores an immutable source SHA256, actual decoded stereo 16-bit/48 kHz frame count, overlap frames and versioned normalization/fade policy. The same canonical timeline gains a music track with repeat placement, source trim, brand gain, fade-in/out and provenance. Shot timing changes regenerate that track. Disable/re-enable, music replacement and history use the existing project/canonical version path; approval is cleared. No independent audio timeline or source-file mutation is introduced. Zero retains the original music document, canonical projection and legacy renderer behavior.

The shared materializer uses exact canonical frame decisions to create a bounded stereo PCM bed. It measures source RMS/peak, applies an RMS gain bounded by the peak limit, and uses linear overlapping fades, including opening and ending fades. Clip count is capped at 128; duration is capped by the existing 180-second narrated timeline limit. The renderer applies the existing frozen brand gain, measured-voice normalization, voice sidechain ducking and limiter. The prepared voice PCM is reused without new inference. No extra global fade duplicates the canonical ending fade.

Both current audible preview and final render use this function and retain `music-loop.wav` plus `music-loop.json`. The receipt binds canonical timeline/track, source/policy/output hashes, actual frame counts, repeat count, measured RMS/peak, gain and unclipped sample count. Unknown/unmeasurable values remain null. Target RMS is a policy, not a claim that final loudness or listening balance achieved that target. Existing final-output loudness measurements remain in full QC.

Review and full QC verify physical source PCM, canonical decisions, receipt shape, output PCM hash/header/frame count, normalization gain, strict safety flags and render-manifest binding. Changed preview music prevents approval. Changed render music produces `failed_qc` without a ready render checkpoint. Current narrated format-family creation checks the physical music source before creating any child. Children inherit canonical mix decisions and require their own fresh preview/review/approval; approval and rights authority are not transferred. Historical verified render checkpoints retain their original replay behavior.

Native tests cover actual decoded PCM and rendered output, signed role/CSRF/revision intake, malformed/nonfinite inputs, excessive repeats, reversible timing/disable, canonical rehash tampering, source/output corruption, strict receipt values, failed-QC output, and atomic family rejection after music mutation. Studio tests retain source-mode capability gating and require a distinct narrated capability. Source-mode audio regressions remain required.

The retained signed rehearsal uses six format children on four actual canvases from a fresh recovery copy. It reuses previously generated genuine local voice PCM and explicitly synthetic tone music with unknown rights. It verifies identical preview/final music beds, unchanged source assets and prior media, final full QC, canonical/provenance/cost/event exports, both-database backup/restore and fresh-process replay. Signed approval decisions are test fixtures. No new inference, paid operation, external call, real publication or Owner acceptance is authorized by this rehearsal.
