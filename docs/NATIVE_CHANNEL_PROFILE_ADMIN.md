# Native Owner channel profile administration

This Wave 7 component supplies workspace-owned channel definitions without changing existing projects. Full multi-niche, Mode A/B, provider, browser/Owner and production acceptance remain open.

Owner can create and edit channel profiles through the Vietnamese Studio dialog, choose approved content/brand/video/subtitle references, set audience/tone/keywords/language and original-audio/music processing preferences, and select target platforms. Publication and analytics enablement remain false. Additional voices, new brand/template definitions, publishing account binding and language providers are separate work. English configuration is representable; the locked Vietnamese narration runtime rejects unconfigured English before inference, after the human approval gate.

The configuration store uses three additive SQLite tables for immutable versions, current state and idempotent request receipts. All keys are workspace scoped. Save requires exact current revision/hash; concurrent or changed-body replays cannot overwrite a version. Archive/restore change lifecycle revision and preserve the definition history. Built-in keys remain read-only. Archived or old definitions cannot create new projects; saved project snapshots remain usable without a registry lookup. Limits are 48 custom profiles and 100 definition versions per profile, with bounded history pagination.

Approved references and the complete resolved content, brand/template and subtitle snapshots are frozen with hashes. The customized audience and tone propagate into Trend Radar handoff, research opportunity and Idea Engine context. Shared core functions are reused; projects and canonical timelines are not migrated. Agent Hub draft creation resolves the same workspace registry inside its existing transaction.

GET administration/history and POST administration require Owner management permission. Authentication, origin and CSRF checks precede body parsing. The Studio keeps text literal, preserves its Owner button through shell replacement, protects unconfirmed drafts, verifies scoped write acknowledgements, clears data on workspace/permission changes and does not replay an ambiguous write outcome. These protections do not establish browser rendering or Owner UAT.

The evidence index is [channel-admin-evidence.json](north-star/channel-admin-evidence.json). Its signed local HTTP rehearsal executes the shipped dialog controller using a fixture DOM: two definition versions, archive/restore through revision four, history and an unchanged existing project. A fresh backup is restored into an owned temporary root and a separate process verifies the registry, complete history and original project, without new jobs or provider calls. Original inputs and historical acceptance artifacts remain intact.
