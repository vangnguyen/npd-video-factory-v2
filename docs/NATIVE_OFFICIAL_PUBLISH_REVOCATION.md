# Owner revocation of Native publication consent

Wave 9 adds `POST /api/projects/{project}/official-publications/{publication}/revoke` with only `expected_snapshot_sha256`. A current signed workspace Owner and CSRF are required before the body is read. This is a local removal of authority and makes no provider request.

The action validates scoped review evidence, revokes all active grants for that workspace/project/publication, and records `official.publication.consent.revoked` once. Exact retries preserve the same state and event. The parent becomes `review_required` with `NATIVE_OFFICIAL_PUBLISH_CONSENT_REVOKED`. Missing/foreign/changed snapshots, unchecked fields, non-Owners, unapproved reviews and completed publications are refused. Completed receipts remain readable and unchanged.

Stopping does not depend on current media, project revision, archive status, rights, provider configuration or an unexpired old grant. It leaves approval history, dispatch version/intent, known private session, acknowledged byte offset and remote ID intact. Current authority is checked before subsequent credential and wire requests. A request already sent cannot be withdrawn by this local action; it performs no remote deletion.

A known initialization response arriving after revocation can still be stored in the existing protected session vault. No additional bytes are authorized. A chunk response arriving after revocation cannot invent accepted progress: local recovery marks it `reconciliation_required` and keeps the explicit revocation on the parent. Fresh explicit Owner renewal is required before querying the existing session. The one-initialization guard remains. A processing reply received after stopping cannot issue a terminal receipt.

Studio exposes **Dừng quyền gửi của yêu cầu này** for an Owner who selects a grant-bearing historical request, including after edits, archiving or active analysis. It does not require another approval/send checkbox. The same scoped history and late-response guards apply. The completed and unapproved controls remain disabled. No UI load automatically sends, renews or revokes.
