# Shared Vision transport hardening

The existing structured Vision adapter now explicitly disables environment proxies and redirects, uses one bounded connection with no keepalive, requests identity encoding, and limits the response to 2 MiB. Supplied response lengths/encodings must be unambiguous and match complete received bytes. Oversized, malformed, compressed or truncated transport evidence refuses without inventing a complete response hash or a cost receipt.

JSON decoding requires UTF-8 and rejects duplicate fields and nonfinite constants in both the response envelope and structured frame output. Non-200 responses cannot be accepted as successful Vision output or followed to another endpoint. Existing typed output, model, schema, token limits, explicit central authorization, timeout classification and complete-response usage/cost contracts remain in place.

The zero-cost test flag must be an explicit boolean and requires an injected test transport; default and built-in network transports refuse that bypass before credential or frame reads. Malformed credentials refuse before extraction/dispatch. The production path still needs its existing configured positive cost envelope and caller admission; this adapter alone grants no human/budget/rights approval.

HTTPX/httpcore request logging is suppressed only within the credential-bearing request and cleanup context, using the existing context-local private wire filter. Normal unrelated logging resumes after success, errors and cancellation. Inline image data is redacted from public provider error diagnostics. Unclassified transport and cleanup errors expose fixed messages and require review without automatic retry; known complete bytes retain their original digest, while unread/partial bytes do not.

Private transport/parser/validation/usage exception causes are suppressed in displayed tracebacks. Typed timeout exception names and safe classification remain in their explicit evidence. Secret-shaped provider request IDs are hashed, without changing the digest of the actual complete response bytes.
