# Independent Native generation worker

`NativeGenerationWorker` connects the durable Native queue to actual scoped
reference intake, provider-neutral generation/reconciliation and validated media
staging. Its independent daemon grants no claim with inactive configuration and
does not make the CPU production worker depend on GPU availability. Protected
provider/workflow drift terminates the affected queue head without repeated
execution. Human HTTP/Assets controls are not wired by this increment.

The worker records reference-intake operations and a unique generation cost
intent before external submission. Official generation is conservatively paid
with unknown estimated/actual price; a configured budget blocks that unknown
exposure before dispatch. Fixtures cannot become paid or real-provider evidence.
Unknown billing stays null. Trusted content-free observations retain exact
workspace/workflow/version/ticket binding. Fenced leases renew only while still
valid; expired workers cannot finish or mutate newer state.

An uncertain submission ends `recovery_required`. There is no automatic POST
retry. An explicit recovery request uses the original frozen provider input and
stable client key through read-only job lookup, retaining the original unknown
cost receipt and recording a separate unpaid read operation. If the actual
immutable media stage already exists after a crash, recovery verifies it and
finishes locally with no provider request or new cost intent. Cancellation
requires a bound observed remote confirmation; process shutdown retains
uncertainty rather than sending an unrelated global interrupt.

Success requires actual staged bytes, their immutable physical receipt and
bound cost evidence. An additive terminal receipt ties those to the exact Native
job; it grants neither independent rights verification nor production eligibility.
Duplicate reference hashes are bound in the same deduplicated order as the
existing bridge transport. Original/normalized/thumbnail integrity stays checked.

Asset attachment is a separate acknowledged action bound to request/asset hash,
current project revision and idempotency key. It atomically appends the verified
asset, creates a project version, clears approval and records a frozen receipt.
It does not automatically place footage in the timeline. Replays verify the
original immutable version, even after later edits. Foreign projects, stale
revisions, corrupt media or changed keys/inputs fail. Unknown generated rights
and fixture markers are preserved.

Eleven new worker cases cover actual local pixels/SQLite with explicitly mocked
provider execution, dispatch-before-call, timeout/read-only reconciliation,
post-stage crash recovery, observed cancellation, explicit import/replay,
tampering/fences/default-inactive reopen, protected configuration drift and an
unknown-price budget block before an official-mode request. The affected Native
worker/media/queue/registry/reference/cost/observability suite passes 78 tests.

`scripts/north_star_native_generation_worker.py` connects actual Native execution
to an authenticated bridge on an independent async loop and mocked GPU APIs.
It produces three actual 640x360 outputs, including an image-to-video result and
inpaint with duplicate references. The bridge actually compiles approved fixture
graphs, registers and fully decodes PNG/MP4 binaries; no result is injected.
One lost Native submission reply reconciles through lookup, and one injected
post-stage crash recovers without additional calls. Exactly three Native
generation submissions and three mock GPU prompt writes occur. Three explicit
imports and six cost operations retain unknown actual billing and zero paid
operations. Separate-process default-inactive exact replay verifies histories,
receipts and physical media. External recovery `native-generation-worker-n2`
contains 22 exports. The earlier n1 rehearsal is retained before final review
adjustments.

These are actual media/persistence/bridge execution and mock provider tests.
No actual AI model/GPU, licensed external content, paid generation, Owner UAT,
real publishing, Agent Hub receiver or production deployment is claimed.
