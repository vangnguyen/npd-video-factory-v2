# Native official Vision review in Assets

The shot-based Studio now exposes the signed official Vision workflow through a separate Assets card. The existing fixture controls and Session contract remain unchanged. The new card is initialized only for the existing Vision-review capability in a registry-authenticated session. Construction, project selection, controls, reload and history reads never create or process an analysis.

An Owner explicitly reads protected public configuration and existing measured source frames, selects the exact profile/source, enters a positive VND ceiling and a 60–900 second window, and acknowledges sending those frames. Protocol mocks require a separate raw acknowledgement. Creating the finite request and processing it are separate buttons. The original deadline, source, configuration and maximum cost are retained; replay cannot renew them. Cancellation is local and does not claim remote rollback. Unknown outcomes cannot be resent. The controller retains bounded same-project keys across uncertain replies and blocks dirty, active, archived, busy, role-changed or expired contexts.

Scoped readers can inspect original history without a current provider configuration or key. The card displays original source images, structured captions, descriptions, objects, OCR, environment, action, sampled quality, confidence and thumbnail candidates as plain text. Frame links are confined to the exact signed project/media-frame route. Calculated token cost is separate from the nullable billed cost. Mock results explicitly state that no semantic inference occurred. Four center-crop attention recommendations do not claim continuous tracking or mutate the canonical timeline. The raw saved record is folded behind a disclosure.
