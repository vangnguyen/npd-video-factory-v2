## Integration decisions

1. Keep the existing Native shot view as the default. Do not create another project or timeline source of truth for advanced editing. Use adapters/projections and the current optimistic revision/hash boundary.
2. Reuse the existing structured analysis, Vision, media-plan, publishing, analytics and bridge domain/services. A source file or fixture does not establish that the Native UI can use that capability.
   Native source analysis, immutable transcript revisions, canonical source-footage edits and original-audio proxies now reuse pure shared engines in Native's existing store. Native source final rendering/preview-bound approval, linked shot/advanced editing, supporting-media placement and opt-in normalization/music ducking are now implemented with local-real synthetic fixtures. Source identity rebinding and independent unapproved duplication are now implemented and locally rendered without parent mutation or provider dispatch. Reviewable Native Top 3/Top 5 Auto Shorts now atomically create independent unapproved drafts with complete-speech protection, durable idempotency, saved scene evidence and checksum-bound reuse. Versioned final-effects Native previews now use the same private renderer/composition and exact canonical audio as final, with an explicit lower-resolution profile and final-review boundary. Historical lightweight proxies stay intact. Four-ratio center fallback and reviewable numerical manual crop paths now persist/render through the shared source-seconds engine without altering audio/captions; provider tracking remains explicitly NOT_CONFIGURED. Native CPU frame jobs now retain actual checksum-bound PNG samples and typed pixel facts, feeding scene/highlight/Shorts ranking, supporting-media physical-quality tie-breaks and review-only thumbnail candidates. Copied projects reuse immutable samples with explicit evidence lineage. Semantic output remains null/NOT_CONFIGURED; sampled duplicates do not certify full-video freezing. Genuine structured Vision/autotracking and spoken-source/current Native browser acceptance remain required.
3. Use additive, versioned documents and isolated test databases first. Any destructive migration pauses only that action for explicit Owner review.
   Official Pexels/Pixabay stock adapters now implement bounded search/get/download with durable workspace-scoped 24h caching, provenance and null unavailable relevance metrics. HTTP contracts and persisted MediaPlan integration are mock-tested. Native stock controls, full downloaded-media decoding/production acceptance and credential/right admission remain incomplete. No external provider call was made.
4. Preserve raw provider evidence, original uploads, accepted artifacts and old renders. New quality policies create new revisions; they must not retroactively alter or recertify historical media.
5. Do not reserve invented observed trend/analytics/cost values. Mock payloads are clearly labeled; unknown metrics and billed costs remain null.
6. Each capability change is a separate reviewable commit. Do not merge protected main. Preserve milestone commits remotely and retain the recovery bundle.

## Required external gates

Owner watch/listen UAT is required for Phase 10 certification. It does not block further safe source implementation. Real publishing requires separate explicit enablement and configured authorized credentials. Missing OAuth/API secrets and approved provider budgets are requested only for concrete real acceptance after mock architecture is complete. GPU acceptance needs configured approved models/workflows. Docker/Linux acceptance needs an isolated available runtime; production deployment requires separate Owner approval.
