# ComfyUI generation lifecycle hooks

The existing provider-neutral ComfyUI generation adapter now accepts optional trusted server callbacks: asynchronous `on_job` and synchronous `cancel_requested`. No browser/provider request can supply these callbacks. They are a building block for Native Studio's durable generative job integration, which remains open.

After the approved workflow submission and every poll, the observer receives a strict `comfyui-generation-observation-v1` projection: provider job ID, workspace, workflow/version, actual status and available progress. Missing progress remains null. It receives no prompt, reference images, token, provider failure text or result body. Bounds reject malformed progress/status/version before observation. A fresh copied DTO prevents the observer from mutating the provider job or artifact result. If the durable observer fails after submission, the adapter stops rather than submitting/polling again; its caller must retain the dispatch ambiguity and require reconciliation.

A boolean cancellation check can stop before submission with zero requests. After a job exists it can issue exactly one authenticated `POST /v1/jobs/{bound_id}/cancel` to the independent Video Factory bridge. It does not call a global GPU interrupt, cancel another job or retry a write. Job/workspace/workflow binding is checked before observing the cancel response. Non-200 cancellation fails with a safe code instead of provider response text or an automatic retry. A race that returns actual success preserves that result; it is not falsely recorded as cancelled. If cancellation is still pending the adapter continues bounded status reads until a terminal response or the existing timeout.

Existing callers without hooks retain their current contract, approved mode routing and serialization. Service authentication, scope, registered binary identity/hash/MIME checks, unknown generation rights, fixture markings, non-production eligibility and unknown GPU/billed cost remain. Hooks grant no execution enablement, paid budget, retry, project approval or publishing authority.

Tests use explicit HTTP wire fixtures. They cover observed queued/running/completed progress, unknown progress, callback isolation/failure, cancellation before submit, a single targeted cancel, cancellation/success races, malformed observations, foreign cancel receipts and unknown cancellation outcomes. Existing mode/manifest, binary, generation scope and media-intelligence API suites run with them. No GPU workflow, real provider, secret, paid action, actual media generation, browser/Owner UAT, Hub call, publication or deployment is claimed.

Remaining Native work includes its persistent request/claim/provider ticket/progress/cancel/recovery tables, configured protected bridge factory and approved workflow checks, scoped reference staging, independent worker/cost admission, actual full local result decode and explicit project attachment/Assets controls. Existing bridge queue/artifact components are reused. Checked-in non-executable graphs remain NOT_CONFIGURED until reviewed model/workflow/GPU provisioning and separate genuine acceptance.
